# KOBI Project Memory Index

이 폴더는 KOBI가 프로젝트를 더 정확하게 이해하기 위한 프로젝트 메모리입니다.

## 문서 목록

- PROJECT_SUMMARY.md: 프로젝트 전체 요약
- ARCHITECTURE.md: 아키텍처와 레이어 구조
- FLOW.md: 주요 업무 호출 흐름
- API_GUIDE.md: API/인터페이스 분석 기준
- CODING_GUIDE.md: 코드 작성/리뷰 기준
- OPERATIONS.md: 운영 반영 및 점검 기준
- TROUBLESHOOTING.md: 장애 분석 기준

## 사용 원칙

KOBI는 작업 유형에 따라 관련 문서를 먼저 확인한 뒤 소스를 분석한다.

단, 이 문서는 보조 정보이며 실제 소스와 다를 수 있다.  
최종 판단 전에는 반드시 관련 소스를 다시 확인한다.
