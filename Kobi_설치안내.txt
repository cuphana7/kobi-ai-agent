============================================================
 [1] CLI 전용 설치본  (필수)  -  Kobi_Installer_v*.zip
============================================================
 명령 창에서 'kobi' 명령어로 AI 도우미를 실행하는 기본 설치본입니다.

 설치 방법
 ---------
 1. Kobi_Installer_v*.zip 을 로컬 디스크의 원하는 폴더로 복사합니다.
    (예: C:\Kobi\CLI  — 네트워크/동기화 폴더가 아닌 로컬 폴더를 권장합니다.)
 2. 압축을 풉니다. 안에 'Kobi_Installer' 폴더가 생깁니다.
 3. Kobi_Installer 폴더 안의 'Install-Kobi.cmd' 를 더블클릭합니다.
 4. 검은 설치 창이 뜨고 자동으로 진행됩니다. "설치가 성공적으로 완료되었습니다" 가
    나오면 아무 키나 눌러 창을 닫습니다.

 사용 방법
 ---------
 1. 새 PowerShell 또는 CMD(명령 프롬프트) 창을 엽니다.
    (설치 중 PATH가 갱신되므로, 반드시 '새 창'을 열어야 kobi 명령이 인식됩니다.)
 2. 분석하려는 프로젝트 폴더로 이동합니다.
       cd C:\work\my-project
 3. 도우미를 실행합니다.
       kobi
    - 긴 지침문을 클립보드에 복사(Ctrl+C)한 뒤 바로 실행하려면(PowerShell):
       kobi -p (Get-Clipboard)


============================================================
 [2] GUI(데스크톱 앱) 설치본  (선택)  -  Kobi_Installer_gui_v*.zip
============================================================
 명령어 대신 창(GUI)으로 대화하고 싶은 사용자를 위한 그래픽 앱입니다.
 이 설치본은 GUI 실행에 필요한 구성요소를 모두 포함(자체 완결형)합니다.

 설치 방법
 ---------
 1. Kobi_Installer_gui_v*.zip 을 로컬 디스크의 '별도 폴더'로 복사합니다.
    (예: C:\Kobi\GUI  — CLI 설치본과 같은 폴더에 겹쳐 풀지 마세요. 폴더명이 같습니다.)
 2. 압축을 풉니다. 안에 'Kobi_Installer' 폴더가 생깁니다.
 3. Kobi_Installer 폴더 안의 'Install-Kobi.cmd' 를 더블클릭합니다.
 4. 자동으로 데스크톱 앱이 설치됩니다. 완료 메시지가 나오면 창을 닫습니다.

 사용 방법
 ---------
  - Windows 시작 메뉴에서 'Kobi' 를 검색해 실행합니다.
  - 사내 vLLM에 사전 연결되어 있어, 최초 실행부터 바로 대화할 수 있습니다.

 참고
 ----
  - GUI만 필요하다면 CLI 설치 없이 이 설치본만 설치해도 GUI는 동작합니다.
    다만 사내 배포 기준은 'CLI 필수 + GUI 선택'이므로, 두 설치본을 모두 설치하는 것을
    권장합니다. (CLI 설치본과 GUI 설치본은 서로 다른 폴더에 각각 압축 해제/설치하세요.)


============================================================
 [3] 스킬 번들  (선택)  -  Kobi_Skills_v*.zip
============================================================
 특정 업무용 기능(스킬)을 추가합니다. CLI/GUI 모두에서 인식됩니다.
 포함 스킬: jennifer-monitor, project-bootstrap, frism-cm, office-edit, kbpay-service-check

 설치 방법
 ---------
 1. 파일 탐색기 주소창에  %USERPROFILE%\.qwen  를 입력해 해당 폴더를 엽니다.
    (CLI 또는 GUI 설치를 먼저 마치면 이 .qwen 폴더가 자동으로 만들어져 있습니다.)
 2. Kobi_Skills_v*.zip 을 열고, 그 안의 'skills' 폴더를 위 .qwen 폴더 안으로
    복사(붙여넣기)합니다.
    - 최종 경로가  %USERPROFILE%\.qwen\skills\  가 되면 됩니다.
    - 이미 skills 폴더가 있으면 '병합/덮어쓰기' 로 진행합니다.
 3. Kobi(CLI 새 창 또는 Desktop)를 다시 실행하면 스킬이 인식됩니다.

 참고
 ----
  - 스킬의 node 스크립트는 CLI/GUI 설치가 PATH에 등록한 node로 실행됩니다.
    (별도 node 설치가 필요 없습니다. 스킬 사용 전에 [1] 또는 [2]를 먼저 설치하세요.)


============================================================
 제거(언인스톨) 방법
============================================================
  - CLI / GUI 설치본: 압축을 풀었던 'Kobi_Installer' 폴더 안의
    'Uninstall-Kobi.cmd' 를 더블클릭하면 제거됩니다.
    (CLI, GUI를 모두 설치했다면 각 폴더에서 각각 실행하세요.)
  - 스킬만 제거: %USERPROFILE%\.qwen\skills 폴더에서 해당 스킬 폴더를 삭제합니다.


============================================================
 자주 묻는 질문 / 문제 해결
============================================================
  Q. 'kobi' 명령을 못 찾는다고 나옵니다.
  A. 설치 후 열려 있던 창은 PATH가 반영되지 않습니다. '새' 명령 창을 여세요.
     그래도 안 되면 로그아웃 후 재로그인하거나 PC를 재시작하세요.

  Q. 설치 창이 중간에 실패합니다.
  A. Kobi 관련 창(CLI/Desktop)을 모두 닫은 뒤 Install-Kobi.cmd 를 다시 실행하세요.
     설치본은 반드시 '로컬 디스크' 폴더에서 실행하세요(네트워크/동기화 폴더 지양).

  Q. 관리자 권한이 필요한가요?
  A. 아니요. 본인 계정에만 설치되는 방식이라 관리자 권한 없이 설치됩니다.

  Q. GUI에서 모델 연결/키 오류가 납니다.
  A. 사내 vLLM에 키 인증이 켜진 경우, GUI 설정 또는
     %USERPROFILE%\.qwen\settings.json 에 키를 반영해야 할 수 있습니다.
     자세한 사항은 사내 배포 관리자에게 문의하세요.
